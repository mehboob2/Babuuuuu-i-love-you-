# Birthday Video Quest 💙

A premium, mobile-friendly birthday video journey with **10 locked chapters**. The next interface opens only after the current video ends and the visitor taps **Complete chapter**.

## Files

Keep all files in the same root folder:

- index.html
- style.css
- script.js
- birthday.mp3 (optional background music)
- v1.mp4
- v2.mp4
- v3.mp4
- v4.mp4
- v5.mp4
- v6.mp4
- v7.mp4
- v8.mp4
- v9.mp4
- v10.mp4

## Important

- Names must be exactly lowercase: `v1.mp4` through `v10.mp4`.
- Add your videos beside `index.html`, not inside a folder.
- Music autoplay can be blocked by mobile browsers; tap once on the page.
- For GitHub Pages, commit and push all files, then refresh with cache cleared.
- The website uses Google Fonts through a web link; it still works with fallback fonts if the network is unavailable.
